# model/lexicon/cs — the Czech lexicon

`model lexicon locale cs`. The only authored locale: the `en` locale is not authored (NH-D8); the model's per-locale
mechanism stays, so one can be added later without touching anything else.

- `members/` — the member word lists, seeded at M0 S0.1 T5 (see its README).
- `terms.ttrm` · `labels.ttrm` — M3 S3.1.
