# model/er — the er layer (M1)

`model er`: the ≈ 75 entities (the inventory's table names, singular; logical attributes without prefixes), the
relations, the stacked logical queries (`sales`, `trade_spend`, `receivable`, `pl_month`, …) and the row rules by
realm group (design `07` §2, contracts §6). Arrives at M1 S1.1–S1.2; empty at M0.
